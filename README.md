The museum label a museum in the year 3000 puts beside an ordinary object from today: a sticky note. The curators of 3000, having never seen one in use, read it as a tiny paper prayer stuck to a glowing box — and note, deadpan, that most of them read "do not forget", and most were forgotten.

## How it works

`main.py` builds the label from three fragments, keeps two rejected drafts beside it with the reason each one lost, and checks the winner before writing it: 1–200 characters, UTF-8, not only whitespace, one line, no trailing newline. The checked line goes to `/output/entry.txt`.

```sh
python3 main.py
```
